# B&M Acquisition of Poundland - M&A Valuation & Financial Analysis

## Overview

Independent M&A analysis assessing a hypothetical acquisition of Poundland by B&M European Value Retail S.A.

The project evaluates the transaction from the perspective of B&M as the acquirer, combining standalone valuation, transaction modelling, synergy analysis and post-acquisition financial impact.

**Transaction date:** 21 August 2026
**Acquisition premium:** 15%
**Equity purchase price:** £386.9m
**Transaction enterprise value:** £434.3m
**Financing:** 50% cash / 50% acquisition debt

## Analysis

The project includes:

* Historical financial analysis and five-year operating forecasts
* Discounted cash flow (DCF) valuation
* Comparable company valuation
* Blended standalone valuation
* Acquisition premium and transaction structure analysis
* Revenue and cost synergy analysis
* Store rationalisation and integration cost analysis
* Accretion / dilution analysis
* Free cash flow impact
* Financing and leverage analysis
* Purchase price, synergy and financing sensitivities
* Investment recommendation

## Key Findings

The analysis supports proceeding with the acquisition at a **15% premium**, subject to purchase-price discipline and successful integration.

Key outputs from the base case include:

| Metric                            | Base Case |
| --------------------------------- | --------: |
| Standalone Poundland equity value |   £336.4m |
| Equity purchase price             |   £386.9m |
| Transaction enterprise value      |   £434.3m |
| FY30E annual EBITDA synergies     |    £61.5m |
| FY28E EPS accretion               |      3.5% |
| FY30E EPS accretion               |     31.0% |
| FY30E incremental FCF             |    £78.0m |
| Cumulative incremental FCF        |   £167.7m |
| Value creation                    |    £17.4m |
| Pro forma ND / EBITDA             |     1.58x |

The model indicates a maximum value-creating purchase price of approximately **£404.2m**, equivalent to a **20.2% acquisition premium**. This provides **£17.4m of purchase-price headroom** relative to the base-case transaction.
